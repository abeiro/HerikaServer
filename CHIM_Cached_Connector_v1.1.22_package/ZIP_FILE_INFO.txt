   grep -n "Thinking Config:" /path/to/HerikaServer/connector/openrouterjsoncached.php
   Should find logging statement around line 314

================================================================================
FREQUENTLY ASKED QUESTIONS
================================================================================

Q: Do I need to update the database?
A: No, this is a pure code update. Database schema unchanged.

Q: Will this break my existing connectors?
A: No, existing connectors will work immediately. Settings that were manually
   set in the database will now actually work.

Q: Do I need to reconfigure all my connectors?
A: No, existing configurations are preserved. You only need to reconfigure if
   you want to enable thinking/reasoning features.

Q: Can I skip v1.1.20 and go straight from v1.1.18 to v1.1.22?
A: Yes, absolutely. v1.1.20 was an incomplete fix. v1.1.22 is the complete fix.

Q: Is v1.1.19 safe to use?
A: No, v1.1.19 is broken. Upgrade to v1.1.22 immediately if using v1.1.19.

Q: Which files are most critical for the fix?
A: ui/core/llm_connectors.php (critical), connector/openrouterjsoncached.php,
   and connector/openrouterjsoncached_verbose.php

Q: Will this affect my NPC profiles?
A: No, this only affects LLM connector configuration. NPC profiles use a
   different metadata editor that already worked correctly.

Q: Can I rollback if something goes wrong?
A: Yes, restore from backup. See "Rollback Instructions" in
   INSTALLATION_INSTRUCTIONS.txt

Q: How do I know if the installation worked?
A: Settings should persist after clicking Save. Check browser DevTools for
   <input name="metadata"> hidden field in form HTML.
