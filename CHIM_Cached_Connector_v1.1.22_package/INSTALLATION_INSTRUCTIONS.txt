BACKUP YOUR INSTALLATION (CRITICAL!)
================================================================================

Before proceeding, backup these directories:

cd /path/to/HerikaServer

# Backup connector files
cp -r connector connector.backup_$(date +%Y%m%d)

# Backup library files
cp -r lib lib.backup_$(date +%Y%m%d)

# Backup UI files
cp -r ui ui.backup_$(date +%Y%m%d)

# Backup function files
cp -r functions functions.backup_$(date +%Y%m%d)

# Backup prompt files
cp -r prompts prompts.backup_$(date +%Y%m%d)

# Backup config (if modifying)
cp -r conf conf.backup_$(date +%Y%m%d)

If something goes wrong, you can restore with:
rm -rf connector && mv connector.backup_YYYYMMDD connector
(repeat for other directories)

INSTALLATION STEPS
================================================================================

1. EXTRACT PACKAGE
   ---------------
   unzip CHIM_Cached_Connector_v1.1.22_package.zip
   cd CHIM_Cached_Connector_v1.1.22_package

2. COPY CONNECTOR FILES
   -------------------
   cp connector/openrouterjsoncached.php /path/to/HerikaServer/connector/
   cp connector/openrouterjsoncached_verbose.php /path/to/HerikaServer/connector/

3. COPY LIBRARY FILES
   -----------------
   cp lib/core/llm_connector.class.php /path/to/HerikaServer/lib/core/
   cp lib/chat_helper_functions.php /path/to/HerikaServer/lib/

4. COPY UI FILES (CRITICAL FOR THE FIX!)
   ------------
   cp ui/core/llm_connectors.php /path/to/HerikaServer/ui/core/
   cp ui/core/tmpl/metadata_json_editor.php /path/to/HerikaServer/ui/core/tmpl/

5. COPY FUNCTION FILES
   ------------------
   cp functions/functions.php /path/to/HerikaServer/functions/
   cp functions/json_response.php /path/to/HerikaServer/functions/

6. COPY PROMPT FILES
   ----------------
   cp prompts/simple_format_prompt.php /path/to/HerikaServer/prompts/
   cp prompts/simple_format_prompt_minimal.php /path/to/HerikaServer/prompts/
   cp prompts/dialogue_prompt.php /path/to/HerikaServer/prompts/

7. SET PERMISSIONS
   ---------------
   cd /path/to/HerikaServer
   chmod 644 connector/openrouterjsoncached*.php
   chmod 644 lib/core/llm_connector.class.php
   chmod 644 lib/chat_helper_functions.php
   chmod 644 ui/core/llm_connectors.php
   chmod 644 ui/core/tmpl/metadata_json_editor.php
   chmod 644 functions/*.php
   chmod 644 prompts/*.php

8. CLEAR CACHES
   ------------
   # Clear PHP opcache if enabled
   # Method varies by setup - typically:
   # - Restart PHP-FPM: systemctl restart php-fpm
   # - OR restart Apache: systemctl restart apache2
   # - OR just wait 60 seconds for opcache to expire

   # Clear browser cache
   # - Hard reload: Ctrl+Shift+R (Windows/Linux) or Cmd+Shift+R (Mac)
   # - Or clear browser cache manually

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: Settings don't save (reset after clicking Save)
SOLUTION:
   1. Check browser console (F12) for JavaScript errors
   2. Verify this in browser DevTools Console:
      document.querySelector('input[name="metadata"]')
      Should return: <input type="hidden" name="metadata" ...>
      If null: ui/core/llm_connectors.php wasn't updated correctly
   3. Hard reload browser (Ctrl+Shift+R)
   4. Clear browser cache completely

PROBLEM: Settings save but don't work (connector doesn't use them)
SOLUTION:
   1. Check log/cache.log for diagnostic output
   2. Should see: "Thinking Config: toggle=..."
   3. If not, connector files weren't updated
   4. Verify connector file VERSION shows v1.1.22

PROBLEM: "consolidation is not defined" error
SOLUTION:
   1. Clear browser cache
   2. Hard reload (Ctrl+Shift+R)
   3. Verify metadata_json_editor.php is in ui/core/tmpl/
   4. Check PHP error log for file not found errors

PROBLEM: Page shows blank or PHP errors
SOLUTION:
   1. Check PHP error log (location varies by setup)
   2. Common issue: File permissions too restrictive
   3. Try: chmod 644 on all copied files
   4. Verify all files copied successfully

PROBLEM: Database errors about metadata field
SOLUTION:
   1. Metadata column should exist in core_llm_connector table
   2. Run: DESCRIBE core_llm_connector;
   3. Should have: metadata (TEXT or LONGTEXT)
   4. If missing, run database migration for CHIM 2.0.3

ROLLBACK INSTRUCTIONS
================================================================================

If you need to rollback to your previous version:

1. Stop CHIM processes

2. Restore from backup:
   cd /path/to/HerikaServer
   rm -rf connector lib ui functions prompts
   mv connector.backup_YYYYMMDD connector
   mv lib.backup_YYYYMMDD lib
   mv ui.backup_YYYYMMDD ui
   mv functions.backup_YYYYMMDD functions
   mv prompts.backup_YYYYMMDD prompts

3. Clear caches (PHP opcache + browser)

4. Restart CHIM

Note: Database data is not affected by rollback. Any connectors configured
with thinking settings will simply have those settings ignored by the old
connector code.
