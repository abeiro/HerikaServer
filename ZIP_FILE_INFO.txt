TROUBLESHOOTING FORMAT ISSUES:
------------------------------
If you see simple format output when JSON is selected:

1. **Check error logs** for debug entries:
   ```bash
   tail -100 /var/log/apache2/error.log | grep "CRITICAL DEBUG"
   ```

2. **Look for**:
   - "Response Format Setting: simple" (should be "json")
   - "Simple format instruction created" (should be "JSON format instruction created")

3. **If format is wrong**:
   - Metadata not being saved correctly in database
   - Wrong connector being used by active profile
   - Cache files need to be deleted

4. **Delete cache files**:
   ```bash
   rm -f /path/to/HerikaServer/tmp/system_cache_*.tmp
   rm -f /path/to/HerikaServer/tmp/combined_dialogue_cache_*.tmp
   ```
