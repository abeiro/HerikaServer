WHAT'S NEW IN v1.0.23:
----------------------
🔧 **BUG #10 FIX (CRITICAL)**: Regex no longer consumes user's personal formatting
   • Fixed: `:?` in regex was consuming colons from user's personal roleplay format
   • User format example: `: action description :` dialogue
   • Root cause: Optional colon `:?` in pattern matched user's formatting colons
   • Solution: Removed `:?` from regex, added explicit colon-stripping logic
   • Now supports:
     - Strips format delimiter colons: `(mood): text` → `text`
     - Preserves user's personal formatting colons in message content
     - Handles both immediate and spaced colons: `mood):` or `mood) :`
   • All 17 test cases pass (test_simple_format_regex.php)
