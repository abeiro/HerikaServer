# CHIM Cached Connector v1.1.22 - Installation Instructions

## IMPORTANT: READ BEFORE INSTALLING

This package contains critical fixes for the thinking toggle save bug.
Always backup your files before proceeding.

---

## Installation Steps

### Step 1: Backup Your Current Installation

CRITICAL: Create a complete backup before proceeding!

```bash
# Option A: Full backup (recommended)
cp -r /path/to/HerikaServer /path/to/HerikaServer.backup.$(date +%Y%m%d)

# Option B: Backup specific files
mkdir -p ~/herika_backup_$(date +%Y%m%d)
cp -r HerikaServer/connector ~/herika_backup_$(date +%Y%m%d)/
cp -r HerikaServer/lib ~/herika_backup_$(date +%Y%m%d)/
cp -r HerikaServer/ui ~/herika_backup_$(date +%Y%m%d)/
```

### Step 2: Stop CHIM Server (if running)

Stop the server to prevent file conflicts:

```bash
# Stop docker container (if using docker)
docker stop herika_server

# Or stop Apache/nginx (if standalone)
sudo systemctl stop apache2
```

### Step 3: Extract Package

Extract the contents of this zip file:

```bash
# Navigate to CHIM server root
cd /path/to/HerikaServer

# Extract package (this will overwrite files!)
unzip CHIM_Cached_Connector_v1.1.22_package.zip

# Move files from package directory to root
cp -r CHIM_Cached_Connector_v1.1.22_package/* .
```

### Step 4: Verify File Updates

Check that critical files were updated:

```bash
# Check llm_connectors.php has the fix
grep -n 'textarea name="metadata"' ui/core/llm_connectors.php

# Check metadata_json_editor.php doesn't have debugger
! grep -n 'debugger;' ui/core/tmpl/metadata_json_editor.php && echo "Debugger removed ✓"

# Check connector files exist
ls -lh connector/openrouterjsoncached*.php
```

### Step 5: Set Proper Permissions

Ensure files have correct permissions:

```bash
# Set ownership (replace www-data with your web server user)
sudo chown -R www-data:www-data connector/ lib/ ui/ conf/ functions/ prompts/

# Set file permissions
find . -type f -exec chmod 644 {} \;
find . -type d -exec chmod 755 {} \;

# Make PHP files executable if needed
chmod +x connector/*.php
```

### Step 6: Clear Caches

```bash
# Clear PHP opcode cache (if using OPcache)
# This ensures updated PHP files are loaded
sudo systemctl restart php8.1-fpm  # Adjust version as needed

# OR (if using Apache module)
sudo systemctl restart apache2
```

### Step 7: Clear Browser Cache

In your web browser:
- Chrome/Edge: Ctrl+Shift+Del → Clear cached images and files
- Firefox: Ctrl+Shift+Del → Cached Web Content
- Safari: Cmd+Option+E

### Step 8: Restart CHIM Server

```bash
# Start docker container (if using docker)
docker start herika_server

# Or start Apache/nginx (if standalone)
sudo systemctl start apache2
```

### Step 9: Test Thinking Toggle Fix

1. Open browser and navigate to: `http://your-server/ui/core/llm_connectors.php`
2. Click on an existing connector to edit it
3. Scroll to "Toggle Thinking" section
4. Enable the "Toggle Thinking" checkbox
5. Enter "2000" in "Thinking Tokens"
6. Select "medium" from "Effort Level" dropdown
7. Click "Save" button
8. Verify no JavaScript errors in browser console (F12)
9. Reload the page
10. Edit the same connector again
11. **VERIFY:** Toggle Thinking is still checked
12. **VERIFY:** Thinking Tokens shows "2000"
13. **VERIFY:** Effort Level shows "medium"

SUCCESS: If all values persisted, the fix is working! ✓

### Step 10: Verify Database (Optional)

Connect to your PostgreSQL database and verify:

```sql
-- Check metadata JSON contains thinking settings
SELECT id, label, metadata 
FROM core_llm_connector 
WHERE id = [your-connector-id];

-- Should show JSON like:
-- {"toggle_thinking":true,"thinking_tokens":2000,"effort_level":"medium",...}
```

## Troubleshooting

### Issue: Settings don't save

**Check:**
1. Browser console for JavaScript errors (F12 → Console)
2. File permissions on ui/core/llm_connectors.php
3. PHP error logs: `tail -f /var/log/apache2/error.log`

**Solution:**
- Ensure hidden metadata textarea exists in llm_connectors.php
- Check that consolidation() function is called
- Verify database connection is working

### Issue: Page breaks or shows errors

**Check:**
1. PHP error logs
2. File permissions
3. Backup restoration

**Solution:**
```bash
# Restore from backup
cp -r /path/to/backup/* /path/to/HerikaServer/

# Or restore specific file
cp /path/to/backup/ui/core/llm_connectors.php ui/core/
```

### Issue: Debugger pause when saving

**Check:**
- Open browser DevTools (F12)
- Look for "Paused in debugger" message

**Solution:**
- This should NOT happen in v1.1.22 (debugger removed)
- If it does, verify you extracted the correct version
- Check metadata_json_editor.php line 396 - should NOT have `debugger;`

### Issue: JSON editor doesn't appear

**Expected Behavior:**
- JSON editor is in a collapsible "Advanced" section
- It's collapsed by default
- Click "Advanced: Raw Metadata JSON Editor" to expand

**If still missing:**
- Check browser console for errors
- Verify div id="metadata" exists in llm_connectors.php
- Clear browser cache completely

## Rollback Instructions

If you encounter issues and need to rollback:

### Option 1: Restore from Backup

```bash
# Stop server
sudo systemctl stop apache2

# Restore files
rm -rf connector/ lib/ ui/ conf/ functions/ prompts/
cp -r /path/to/backup/* .

# Restart server
sudo systemctl start apache2
```

### Option 2: Selective Rollback

Restore only specific files that are causing issues:

```bash
# Example: Restore just llm_connectors.php
cp /path/to/backup/ui/core/llm_connectors.php ui/core/

# Clear PHP cache
sudo systemctl restart apache2
```
