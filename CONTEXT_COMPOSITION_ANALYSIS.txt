## Current Context Structure (from main.php lines 1499-1513)

The system prompt sent to the LLM is built as follows:

```
$head[] = array('role' => 'system', 'content' =>
    strtr($GLOBALS["PROMPT_HEAD"] .
          "\n\n<character>\n" . $GLOBALS["HERIKA_PERS"] . $dynamicBiography . "\n</character>\n\n" .
          "<knowledge>\n" . $GLOBALS["OGHMA_HINT"] . "\n</knowledge>\n\n" .
          "<general_instructions>\n" . $GLOBALS["COMMAND_PROMPT"] . "</general_instructions>\n" .
          $rumors . "\n",
    ["#PLAYER_NAME#"=>$GLOBALS["PLAYER_NAME"],"#HERIKA_NAME#"=>$GLOBALS["HERIKA_NAME"]])
);
```

## Component Breakdown:

### 1. PROMPT_HEAD (from conf.sample.php line 8)
```
$PROMPT_HEAD="Let's roleplay in the Universe of Skyrim. If the game director gives you an instruction, you must follow it.";
```
**Purpose**: Sets the roleplay context and establishes director authority
**Source**: conf/conf.sample.php or database conf_opts table


### 2. HERIKA_PERS (Character Biography)
**Purpose**: Static character personality, background, traits, relationships
**Source**: Character profile from database
**Example structure**: Name, race, background story, personality traits, likes/dislikes


### 3. Dynamic Biography (from data_functions.php)
**Purpose**: Dynamically updated character state
**Source**: Built by buildDynamicBiography() function
**Includes**:
- Current personality state
- Current goals
- Current relationships
- Skills and occupations
- Speech style
- Group membership (if applicable)
- Middle-term memory (past events)


### 4. OGHMA_HINT (Knowledge Section) - Optional
**Purpose**: Relevant lore/knowledge retrieved from Oghma database
**Source**: processor/oghma.php memory retrieval system
**Note**: Only included if relevant memories found


### 5. COMMAND_PROMPT (from prompts/command_prompt.php line 31)
```
$COMMAND_PROMPT = "Don't write narrations.";
```
**Purpose**: General instructions for response format
**Source**: prompts/command_prompt.php


### 6. Rumors - Optional
**Purpose**: Current hold-specific breaking news/rumors
**Source**: Database rumors table
**Note**: Only included if character is in a known hold


## Complete Dialogue History Context:

After the system prompt, the context includes:

### 7. World Context ($contextDataWorld)
**Source**: DataLastInfoFor() - last 2 entries of world info
**Purpose**: Recent environmental/game state changes


### 8. Historical Dialogue ($contextDataHistoric)
**Source**: DataLastDataExpandedFor() - last N dialogue entries
**Purpose**: Conversation history
**Note**: Can be filtered to hide narrator dialogue if HIDE_NARRATOR_DIALOGUE enabled


### 9. Current Prompt ($prompt)
**Purpose**: User's current input/question
**Format**: array('role' => 'user', 'content' => $request)

## POTENTIAL "ROLEPLAY QUALITY PROMPT"

Based on code analysis, there is NO extensive "roleplay quality prompt" currently in CHIM 2.0.

The only roleplay-related instructions are:
1. PROMPT_HEAD: "Let's roleplay in the Universe of Skyrim..."
2. COMMAND_PROMPT: "Don't write narrations."
3. TEMPLATE_DIALOG (in dialogue_prompt.php): "Write {NPC}'s next dialogue line. Avoid narrations..."

These are quite minimal and designed to be model-agnostic.
