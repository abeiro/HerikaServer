v1.1.21 (2025-11-15) - CRITICAL BUG FIXES
================================================================================

SUMMARY:
Complete fix for thinking toggle feature. Settings now save AND work correctly.
This is a MANDATORY update for anyone wanting to use thinking/reasoning features.

CRITICAL FIXES:
---------------

1. Fixed settings not saving at all
   Root Cause: Form had no hidden <input name="metadata"> field, causing all
               metadata[...] fields to be ignored during form submission
   Solution: - Added hidden metadata fields to both forms in llm_connectors.php
             - Rewrote consolidation() to collect all metadata[...] fields
             - JavaScript builds JSON object and sets hidden field before submit

2. Fixed settings saved but not working
   Root Cause: Connector read values without type casting, treated strings as
               booleans incorrectly
   Solution: - Added (bool) cast for toggle_thinking
             - Added intval() with empty check for thinking_tokens
             - Added empty check for effort_level
             - Added diagnostic logging for all thinking settings

FILES CHANGED:
--------------

ui/core/llm_connectors.php:
   Line 272: Added <input type="hidden" name="metadata" id="metadata_field">
   Line 1356: Added <input type="hidden" name="metadata" id="metadata_field_main">
   Lines 2063-2123: Complete rewrite of consolidation() wrapper function
                    - Collects all metadata[...] fields
                    - Handles checkbox pairs (hidden + visible)
                    - Converts string booleans to actual booleans
                    - Removes empty values
                    - Sets hidden field for PHP submission
                    - Preserves JSON editor behavior on other pages

connector/openrouterjsoncached.php:
   Line 12: Updated VERSION to v1.1.21
   Lines 310-314: Added type casting and diagnostic logging for thinking config
                  - (bool) cast for toggle_thinking
                  - intval() with empty check for thinking_tokens
                  - Empty check for effort_level
                  - logMessage for configuration values
   Lines 647-659: Added reasoning configuration logging
                  - Log model detection results
                  - Log reasoning enabled state
                  - Log effort level or max_tokens being used

connector/openrouterjsoncached_verbose.php:
   Line 13: Updated VERSION to v1.1.21
   Lines 304-308: Same type casting and logging as main connector
   Lines 959-976: Same reasoning configuration logging
