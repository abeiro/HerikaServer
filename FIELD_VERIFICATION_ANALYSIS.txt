## VERIFICATION SUMMARY
========================

✅ **custom_system_instruction** - Working as documented
   - Location: System prompt (after character bio, within format instructions)
   - Does NOT replace other instructions
   - Appended to format instruction text

✅ **custom_last_instruction** - Working as documented
   - Location: User content array, right before current user message
   - Literally the last thing before model responds
   - Used for injecting recent context or final instructions

⚠️ **IMPORTANT NOTE ABOUT CACHE CONTROL:**

The cache marker calculation (line 476) accounts for custom_last_instruction:
```php
$lastIndex = $totalElements - $dialogue_cache_uncached_count - 1 - $addToIndex;
```

If custom_last_instruction is set:
- $addToIndex = 1
- Cache marker is placed one element earlier
- This keeps custom_last_instruction in the UNCACHED region

This is CORRECT behavior because:
- If you're adding recent context, it should be dynamic (uncached)
- If it were cached, it would freeze that context


## ACTUAL PROMPT STRUCTURE
===========================

When both fields are used, the complete structure is:

1. **System Message** (CACHED):
   ```
   [PROMPT_HEAD: "Let's roleplay..."]
   [Character Name, Race, Background]
   [Dynamic Biography: goals, relationships, skills]
   [Available Actions list]
   [Format Instructions] [custom_system_instruction] Use ONLY this JSON...
   [CACHE MARKER HERE]
   ```

2. **User Message** (partially cached):
   ```
   [World context: location changes, etc.]
   [Dialogue history entry 1]
   [Dialogue history entry 2]
   ...
   [Dialogue history entry N]
   [CACHE MARKER HERE - last 4-6 entries uncached]
   [Dynamic environment: equipment, appearance, combat status] ← At position count-2 before insertion
   [custom_last_instruction] ← IF SET, second-to-last after all insertions
   [Current user request] ← Always last
   ```

3. **Assistant Response** (if using simple format with prefill):
   ```
   [(  ← Prefill to start simple format
   ```
