CHIM Cached Connector v1.3.4 - Package Contents
===============================================

This package contains all files needed to install or upgrade the
CHIM Cached Connector with advanced caching, thinking/reasoning,
flexible quality instruction control, correct custom instruction
placement, true sentence-by-sentence streaming for simple format,
and fixed asterisk/dash preservation in sentence splitting.

KEY FEATURES IN v1.3.4
----------------------

* FIXED ASTERISK/DASH STRIPPING (NEW!)
  - Action markers like "* rises *" now preserved
  - Dashes, hashes, at-signs also preserved
  - Closing quotes/brackets still handled correctly

* TRUE SENTENCE-BY-SENTENCE STREAMING (from v1.3.3)
  - Simple format sentences sent immediately as generated
  - No 75-character accumulation delay
  - Significantly improved perceived responsiveness
  - JSON format unchanged (still uses proper fragment accumulation)

* Fixed custom_system_instruction placement (from v1.3.2)
  - Now in system prompt before dialogue history
  - Properly influences entire conversation

* Conditional "Provide variety" filtering (from v1.3.1)
  - Controlled by minimize_quality_prompt setting
  - Default: enabled (recommended for advanced models)

* Advanced caching support (from v1.2.x)
  - Anthropic, OpenAI, Gemini cache support
  - Dialogue history caching
  - Significant token savings

* Thinking/Reasoning support (from v1.2.x)
  - Works with o1, Claude, Gemini 2.0
  - Configurable effort levels
  - Token budget control

* Flexible response formats (from v1.2.x)
  - JSON: Structured output
  - Simple: Natural language with tags (with streaming!)
