KEY FEATURES IN v1.3.3

✓ TRUE SENTENCE-BY-SENTENCE STREAMING (NEW!)
  - Simple format sentences sent immediately as generated
  - No 75-character accumulation delay
  - Significantly improved perceived responsiveness
  - JSON format unchanged (still uses proper fragment accumulation)

✓ Thinking/Reasoning support (from v1.2.x)

  - Token budget control

✓ Flexible response formats (from v1.2.x)
  - JSON: Structured output
  - Simple: Natural language with tags (now with streaming!)

PERFORMANCE COMPARISON
----------------------

Simple Format Streaming Performance:

v1.3.2 (Before):
- Sentences: "Hello." "How are you?" "I'm well." "What brings you?"
- Buffer accumulation: Wait until 75+ chars
- All 4 sentences sent together after delay
- Noticeable lag between generation and display

v1.3.3 (After):
- Sentence 1: "Hello." → Sent IMMEDIATELY ✓
- Sentence 2: "How are you?" → Sent IMMEDIATELY ✓
- Sentence 3: "I'm well." → Sent IMMEDIATELY ✓
- Sentence 4: "What brings you?" → Sent IMMEDIATELY ✓
- True streaming: Each sentence appears as generated

JSON Format (Unchanged):
- Fragment accumulation still applies
- 75-character minimum preserved
- Necessary for preventing incomplete sentences
- Performance identical to v1.3.2
