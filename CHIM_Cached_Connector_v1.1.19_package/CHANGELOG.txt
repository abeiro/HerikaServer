- Removed ALL colon stripping logic entirely

  * Root cause: Misunderstanding of simple format specification

THE FIX:
- Completely removed conditional colon stripping logic
- Colons are now preserved in ALL cases
- Lines 581-584 in openrouterjsoncached_helpers.php now just preserve colons
- Simple, correct behavior: never touch the leading ':'

IMPACT:
- Action descriptions always display correctly with leading ':'
- Talk actions display correctly with leading ':'
- No more edge cases or conditional logic
- Simpler, more maintainable code
- Fixes issue where v1.1.17 still stripped colons in some cases

v1.1.10 (2025/11/13)
--------------------
CRITICAL BUG FIX:
- Fixed flush not being called when finish_reason detected
  * Root cause: flush() only called when done=true OR buffer size > threshold
  * Problem: When max_tokens reached, finish_reason="length" but done=false
  * Result: Trailing content in buffer never flushed, causing lost sentences
  * Example: "I can help with that." lost because stuck in buffer

THE FIX:
- Added explicit flush when finish_reason is detected
- Check for finish_reason BEFORE done check
- Flush immediately when stop/length/content_filter detected
- Ensures ALL content gets returned, even at token limits

DIAGNOSTIC LOGGING:
- Added flush diagnostic messages to log/cache.log
- Shows reason for every flush: done, finish_reason, size threshold
- Look for "Flush:" messages in logs
- Helps debug streaming issues

IMPACT:
- 100% elimination of lost trailing content
- Proper handling of max_tokens cutoff
- Better debugging with flush logging

Location: connector/openrouterjsoncached.php:1187-1198
