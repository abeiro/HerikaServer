CRITICAL FIXES IN v1.1.19
=========================

**1. THINKING TOGGLE NOT SAVING (UI BUG FIX)**

The thinking toggle, thinking tokens, and effort level settings were not
saving when you pressed the save button. They would just reset to OFF/empty.

Root Cause:
- Forms were missing the hidden <input name="metadata"> field
- JavaScript tried to set form.metadata.value but the field didn't exist
- Settings failed to save silently (wrapped in try-catch)

The Fix:
- Added hidden metadata field to both connector forms
- Extended consolidation() to merge all metadata settings into JSON
- Removes name attributes from array-style fields before submit
- Now all thinking settings save correctly

Impact:
✅ Toggle Thinking checkbox now saves
✅ Thinking Tokens setting now saves
✅ Effort Level setting now saves
✅ All caching settings continue to work
✅ Can now use thinking with o1, DeepSeek-R1, etc.

Location: ui/core/llm_connectors.php:272, 1356, 2063-2152


**2. DIAGNOSTIC LOGGING FOR COLON STRIPPING**

Added comprehensive logging to trace where leading colons are being stripped
from action descriptions in the post-processing pipeline.

v1.1.18 fixed colon stripping in the connector, but users still report
colons being inconsistently removed. This diagnostic logging will help
identify exactly where in the post-processing the colons disappear.

The logging tracks sentences through 6 checkpoints:
1. returnLines() entry (before unmoodSentence)
2. unmoodSentence() entry
3. unmoodSentence() exit
4. After unmoodSentence
5. Before/after TRANSFORMER_FUNCTION
6. Before/after NPC name removal

Log Format:
- ⚠️ markers for sentences starting with colon
- ✅ when colon is preserved
- ❌ when colon gets stripped (with before/after)
- Shows first 60-80 chars for context

How to Use:
- Check log/chim.log after testing
- Look for "[unmoodSentence]" or "[returnLines]" entries
- Find "❌ COLON WAS STRIPPED!" to see where it happens
- Report findings so proper fix can be implemented

Location: lib/chat_helper_functions.php:500-700

TROUBLESHOOTING
===============

Thinking toggle still not saving?
- Clear browser cache
- Check browser console for JavaScript errors
- Verify ui/core/llm_connectors.php was updated
- Check form has <input name="metadata"> field (view source)

Colons still being stripped?
- Check log/chim.log for diagnostic output
- Look for "❌ COLON WAS STRIPPED" markers
- Report which checkpoint shows the stripping
- Include before/after text from logs

minimize_quality_prompt not working?
- Check log/lastlog.log for diagnostic messages
- Verify setting in UI matches connector config
- Ensure DMgetCurrentModel() returns correct model name

Streaming issues?
- Check log/cache.log for buffer processing messages
- Verify finish_reason triggers flush
- Look for "Flush:" messages in logs
